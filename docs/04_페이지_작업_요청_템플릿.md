# 04. 페이지 작업 요청 표준 템플릿 (팀원 공용)

새로운 페이지 구축(또는 기존 페이지 수정)을 요청할 때 아래 양식을 사용합니다.
Claude Code에서는 `/new-page` 또는 `/maintain` 슬래시 커맨드로 동일 양식이 호출됩니다.

---

## 1. 참조 리소스

- PC 디자인 링크: [여기에 PC 피그마 링크 입력]
  (기본값: https://www.figma.com/design/6eO6s3lH8TVv85FWgBekEh/?node-id=1374-2669)
- 모바일 디자인 링크: [여기에 모바일 피그마 링크 입력]
  (기본값: https://www.figma.com/design/6eO6s3lH8TVv85FWgBekEh/?node-id=470-120)
- 컴포넌트 기준 (자동 적용): Component `2031-6499` + **Extended Components `2035-6510`**
  (Pagination·Footer·Table·Year Selector 등은 Extended에 있음 — 두 섹션 모두 전수 확인)
- 레이아웃 기준 (자동 적용): `세부 페이지 디자인 (MO)_이미지 변경` `368-7638` ·
  `세부 페이지 디자인 (PC)_이미지 변경` `1374-2499` — 유사 화면 실측값 크로스 레퍼런스 (뒤틀림 금지)
- 산출물 형태: **Figma 시안 (기본값)** — 코드 구현이 필요할 때만 "퍼블리싱"이라고 명시
- (퍼블리싱 시) 타겟 기술 스택: [예: React(TypeScript), Tailwind CSS, 사내 UI 라이브러리]

## 2. 작업 지시 사항

- (기본 — 디자인 모드) 참고 링크를 분석해 디자인 페이지에 신규 시안 프레임([추가] 표기)을 생성합니다.
  기존 컴포넌트 인스턴스 + 텍스트 스타일 + 변수 바인딩만 사용하고, 기존 프레임·라이브러리는 수정하지 않습니다.
- (퍼블리싱 모드 — 명시 요청 시) 두 링크를 분석하여 하나의 반응형 페이지 컴포넌트로 통합 구축하고,
  피그마의 'Auto Layout' 값을 코드의 Flexbox/Grid 속성으로 정확히 변환하며,
  피그마에 사용된 컴포넌트는 사내 디자인 시스템 컴포넌트로 맵핑합니다.

## 3. 자체 검수 (Self-Confirm) 리포트 요청

산출(시안 또는 코드)을 완료하기 전에 CLAUDE.md 7장의 **현재 모드 체크리스트**로 리포트합니다.

(기본 — 디자인 모드 6항)

- [ ] 결과물이 Figma 시안 프레임인가? (코드·HTML 미생성)
- [ ] 사내 컴포넌트 인스턴스만 조립했는가? (Component + Extended 두 섹션 확인)
- [ ] 텍스트는 텍스트 스타일 ID 연결, 색·radius는 변수 바인딩으로만 지정했는가? (값 복사 금지)
- [ ] 기존 프레임·컴포넌트·변수를 수정하지 않았는가? (`[추가]`/`[수정]` 표기)
- [ ] `컴포넌트 업데이트 필요` 라벨을 전수 집계했는가?
- [ ] 페이지네이션·아이콘·구분선 등 미세 요소까지 인스턴스/스타일/변수 연결을 확인했는가?

(퍼블리싱 모드 — 명시 요청 시)

- [ ] PC/모바일 반응형 레이아웃이 하나의 코드로 통합되었는가?
- [ ] 하드코딩된 스타일(px 단위 폰트 크기, 인라인 컬러 등) 대신
      사내 디자인 토큰(rem, 컬러 변수)을 100% 사용했는가?
- [ ] 사내 디자인 시스템에 없는 임의의 요소를 만들어 낸 부분은 없는가?
      (있다면 어떤 부분인지 명시할 것)

## 자연어 요청 시 표준 확인 절차

팀원이 자연어로 요청하더라도, Claude는 작업 착수 전 아래 형식으로
작업 계획을 먼저 제안하고 확인받습니다.

```
1. [분석]: 첨부된 기획안(스크린샷/문서/Figma 링크)을 읽고 타겟 디자인을 분석하세요.
   - 유지보수/추가할 타겟 화면: [기획안 첨부 또는 Figma 화면 링크]
   - Component(2031-6499)·Extended(2035-6510)에서 사용할 컴포넌트를 파악하고,
     세부 페이지 디자인 (MO/PC)_이미지 변경 페이지(368-7638 · 1374-2499)의
     유사 화면을 크로스 레퍼런스하세요.

2. [실행]: 디자인 페이지에 신규 시안 프레임([추가] 표기)으로,
   기존 컴포넌트 인스턴스 + 텍스트 스타일 ID + 변수 바인딩만 조립해 주세요.
   ※ 코드가 필요한 경우에만 "퍼블리싱으로 구현해줘"라고 명시합니다.

3. [확인]: Self-Confirm 리포트(디자인 모드)를 출력하고
   완성된 시안 프레임의 Figma 링크를 제시해 주세요.
```
