# 03. 디자인 토큰 레지스트리

> **유일한 기준은 Figma `Component` 노드(`2031-6499`)입니다.**
> 아래 값은 이전 작업 세션에서 해당 노드로부터 추출된 값의 기록이며,
> 각 작업 시작 시 Figma MCP로 재검증 후 사용합니다. 문서와 Figma가 다르면 Figma가 우선합니다.
> 모든 값은 CSS 커스텀 프로퍼티로 관리하며, px 하드코딩을 금지합니다.

## 컬러

| 토큰 | 값 | 용도 |
|---|---|---|
| Pm1 (Primary) | `#e4002b` | 주요 액션·강조 |
| Primary Hover | `#c40025` | Primary 호버 상태 |
| Red1 | `#fdefec` | Primary 계열 배경 |
| T1–T4 | Gray scale | 텍스트 위계 |
| L1·L2 | Line | 구분선·보더 |
| Bg1 | Background | 기본 배경 |

## 타이포그래피

- 서체: **Pretendard** (Bold / SemiBold / Medium / Regular)
- Font, Size, Line-height, Letter-spacing은 Component 노드의 텍스트 스타일 토큰을 그대로 사용

## Radius

> Figma `Radius` 변수 컬렉션 기준 (2026.08.31 동기화 — 총 13종)

| 토큰 | 값 | 용도 |
|---|---|---|
| `radius/small` | `8` | 버튼·인풋 등 기본 라운드 |
| `radius/medium` | `12` | 카드·컨테이너 |
| 개별 값 | `4` `5` `6` `7` `10` `20` `22` `28` `37` | 컴포넌트별 지정 값 (예: 체크박스 4, 토글 10) |
| `radius/99` `radius/100` | `99` `100` | 풀 라운드 (pill·원형 버튼) |

## 반응형

- 브레이크포인트: `64rem` (단일 코드베이스 내 Media Query 전환점)

## 관리 원칙

- 모든 값은 `:root`의 CSS 커스텀 프로퍼티로 정의하고 변수로만 참조한다.
- 신규 토큰 발견 시 이 문서에 추가하고, 출처 노드 ID를 함께 기록한다.
