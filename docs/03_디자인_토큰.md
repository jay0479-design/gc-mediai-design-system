# 03. 디자인 토큰 레지스트리

> **유일한 기준은 Figma `Component` 노드(`2031-6499`)와 Figma 변수·텍스트 스타일입니다.**
> 아래 값은 Figma에서 추출한 기록이며(2026.08.31 동기화), 각 작업 시작 시 Figma MCP로 재검증 후 사용합니다.
> 문서와 Figma가 다르면 Figma가 우선합니다. 모든 값은 CSS 커스텀 프로퍼티로 관리하며, px 하드코딩을 금지합니다.

## 적용 원칙 (필수)

1. **텍스트는 반드시 아래 텍스트 스타일 중 하나를 적용**한다 — PC는 `GC/…`, 모바일은 `GC_MO/…`.
   임의의 폰트 크기·행간 조합을 만들지 않는다.
2. **색상·radius는 반드시 Figma 변수 값으로 바인딩**한다 — 값 복사가 아니라 변수 참조.
3. 스타일·변수 목록에 없는 값이 시안에 나타나면 추측 적용하지 말고
   **`컴포넌트 업데이트 필요` 라벨**을 남긴다 (CLAUDE.md 3장).

## Radius

> Figma `Radius` 변수 컬렉션 기준 (2026.08.31 동기화 — 총 13종)

| 토큰 | 값 | 용도 |
|---|---|---|
| `radius/small` | `8` | 버튼·인풋 등 기본 라운드 |
| `radius/medium` | `12` | 카드·컨테이너 |
| 개별 값 | `4` `5` `6` `7` `10` `20` `22` `28` `37` | 컴포넌트별 지정 값 (예: 체크박스 4, 토글 10) |
| `radius/99` `radius/100` | `99` `100` | 풀 라운드 (pill·원형 버튼) |

## 반응형

- 브레이크포인트: `64rem` (단일 코드베이스 내 Media Query 전환점)
- PC 텍스트 스타일(`GC/…`)과 모바일(`GC_MO/…`)의 전환도 이 지점을 기준으로 한다

## 관리 원칙

- 모든 값은 `:root`의 CSS 커스텀 프로퍼티로 정의하고 변수로만 참조한다.
- 신규 토큰·텍스트 스타일 발견 시 이 문서에 추가하고, 출처(Figma 변수/스타일명)를 함께 기록한다.
- Figma에서 변수·스타일을 변경한 날에는 "토큰 문서를 피그마 기준으로 갱신해서 푸시해줘"로 이 문서를 동기화한다.
